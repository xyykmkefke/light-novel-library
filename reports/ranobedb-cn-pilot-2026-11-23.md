## 4. 召回审计

对 500 条逐条检查「候选里存在中文名且标题相近但被拒绝」的情况：

| 情况 | 数量 |
| --- | --- |
| 候选中有中文名且标题相近 | 61 |
| 最终采纳 | 51 |
| 因外传跨系列被拒 | 3（如「ふしぎ遊戯 外伝」不得挂到正传） |
| 因年份超差被拒 | 4（如「フルメタル・パニック! アナザー」vs 1998/2000 的正传） |
| 因命中单卷条目被排除 | 70 个候选（「标题 (3)」「第2巻」这类） |
| 全部候选都无中文名 | 89 条 |

结论：拒绝项均为真实的不该匹配，**未发现有效候选被误杀**；剩余未命中的主因是 Bangumi 没有对应条目或该条目没有中文名，与方案判断一致。

试点中还修掉了一处规则缺陷：`…外伝` 原本会被挂到正传中文名上，现已改为「外传条目不得到正传」，修正后它正确挂到了「期待在地下城邂逅有错吗 外传 剑姬神圣谭」。

## 6. 结论与建议

1. 试点质量达标（误配 2%，阈值 10%），机制可用。
2. **建议扩大到 `v >= 5` 的 1,664 条**：实测 500 条约 2.5 分钟，1,664 条约 8–10 分钟，成本远低于方案原先估计的 1.5–2 小时；按 8–10% 命中率预计再补 80–120 条。
3. 扩大到 1,664 条后统一人工过表（预计约 170 行），逐条标「采纳 / 剔除」，剔除项写入 `data/ranobedb-cn.json` 的黑名单后再出 v1.15.2。
4. 若只想要零风险，可只保留 3 条小说源条目——但收益几乎为零，不建议。
5. 若判定这批「漫画译名」不可接受，则退回方案 C（删映射文件、重建即可），代价是扩展书目继续只有日文名。

### 9.1 复核流程

1. 自动标记 56 条可疑项（`near`/`contain`、年差≥4、中文名≤4 字、中文名含外传、小说源低热度）。
2. 245 条按 82/82/81 拆成 3 份，交 3 个子代理独立判定，各自只输出「错误 / 存疑」条目及理由。
3. 主线逐条回查原始召回数据（平台、册数、年份、bgm 链接）交叉比对，最终确认 6 条错配。

### 9.2 剔除清单（`data/build/ranobedb-cn-pilot/blocklist.json`）

| 日文原名 | 误配中文名 | 原因 |
| --- | --- | --- |
| 魔石グルメ 魔物の力を食べたオレは最強! | 美石家 | 漫画改编的官方译名，非常用译名（应为「魔石美食家」） |
| 機動戦士ガンダムF91 | 机动战士高达 | 目标条目是 1979 年初代高达小说版，不是 F91 |
| ひぐらしのなく頃に解 | 寒蝉鸣泣之时 | 「解」为解答篇续作，中文名丢失系列标记 |
| ゴブリンスレイヤー TRPG | 哥布林杀手 | 本条是 TRPG 规则书，目标条目是漫画 |
| 転生した大聖女は、聖女であることをひた隠す ZERO | 转生后的大圣女，极力隐瞒圣女的身分 | 「ZERO」为前传系列，且年份错位（2022 vs 2019） |
| ローゼンメイデン | 蔷薇少女0 Zero | 中文名指向外传 0 -zero-，与正传对应错误 |

剔除口径：只要中文名把「外伝 / 解 / ZERO / 0 Zero / TRPG / F91」这类区分性标记丢掉，导致显示名指向另一部作品或另一类产品，一律不采纳；仅省略副标题、繁简差异、官方译名不同不在此列。
