# 轻小说库 · 阅读记录

本地优先的轻小说浏览与阅读记录 PWA。内置 Bangumi「轻小说」与「小说」标签合并去重后 4851 条核心数据，另从系列关联补入 7639 卷懒加载卷包，合计 12490 条；其中 789 条为仅「小说」标签的一般小说，默认隐藏。另接入 RanobeDB 扩展书目 8487 个系列（≥2 卷，31254 卷），默认隐藏、按需加载。通过 openBD 补入 3367 个单册 ISBN、850 个系列首卷 ISBN、2950 条日文版发售日，并用 RanobeDB 补系列首卷 ISBN 与缺失卷。无账号、无后端。

## 功能

- **全库浏览**：按年份、题材、类型（轻小说 / 漫画 / 画集 / 指南）筛选；评分 / 热度 / 发售日 / 名称排序
- **系列视图**：默认隐藏系列子卷，只显示系列与独立作品；可一键显示全部系列子卷；开启「含一般小说」后纳入全部一般小说；开启「显示扩展书目」后按需加载 RanobeDB 扩展书目
- **搜索**：中文名、原名、拼音首字母、作者；多关键词交集、`-词` 排除、标题高亮、搜索历史；支持 `作者:` `出版社:` `书系:` `年:` `分:` `题材:` 字段语法
- **我的阅读**：想读 / 在读 / 读完 / 弃读；系列记录读到第几卷；系列详情提供逐卷清单，可展开勾选已读并自动汇总进度、标记下一卷；顶部「继续阅读」只列在读未读满的书并支持一键＋1 卷；详情内一键加减卷、读完全部；系列详情可一键加入全部子卷；读满自动标记读完并记录日期；可按最近加入 / 最近更新 / 我的评分 / 阅读进度 / 名称 / 发售日排序
- **我的书评**：1–10 分个人评分、140 字短评、1000 字笔记；输入自动暂存草稿、重开自动恢复；随记录一起导出、导入与云同步
- **阅读统计**：收藏与状态总览、年度目标进度与节奏（领先 / 落后）、我的评分分布与最常给分、阅读打卡连续天数、历年与月度读完分布、题材偏好、常读作者、想读队列（同作者在读 / 高评分 / 短篇优先，一键开始读）
- **视图**：网格 / 列表 / 看板；按年份、题材、阅读状态分组
- **排序**：贝叶斯加权评分、热度、发售日、名称、卷数、我的评分
- **详情**：作者、插图、出版社、书系、册数、发售日、题材、评分、相似推荐（同作者 / 同书系 / 同题材 / 评分接近并标注理由）、Bangumi 链接；卷进度一键记录，作者、题材、出版社、书系标签可一键筛选
- **数据**：JSON / CSV / Markdown 导出，JSON 导入合并，清空可撤销
- **云同步**：GitHub Gist 双向合并，删除墓碑，失败退避重试（Token 仅存本机）
- **PWA**：iOS 添加到主屏幕、安装引导、离线缓存、封面缓存上限与清理、离线占用统计、明暗主题
- **无障碍**：跳过头部、焦点陷阱、Esc 归焦、状态播报、J/K 键盘导航、44px 触控目标

## 数据

- 来源：Bangumi（bgm.tv），`type=1` 书籍，`tag=轻小说` 与 `tag=小说`，通过镜像 `bgmapi.anibt.net` 抓取
- 扩展来源：RanobeDB（<https://ranobedb.org>，ODbL），日文原名、≥2 卷、与 Bangumi 标题去重；扩展书目无中文名与 Bangumi 评分，保留封面、卷数、起始发售日与 RanobeDB 链接
- 规模：核心 4851 条（轻小说 4062 / 一般小说 789）；系列 1306 / 单册 3545 / 子卷 2160；默认可见 1925 条；重复版本 79 条默认隐藏
- 卷包：7639 条（单行本 + 番外篇 + RanobeDB 补卷），按需加载；展开后共 11625 条轻小说
- 统计：系列内 9799 册，按上/中/下折合 9707 故事卷
- 扩展书目：8487 个系列 / 31254 卷，默认隐藏，开关打开后按需加载
- 字段：作者 4757 条、插图 3714 条、书系 3603 条、出版社 4797 条、发售日 4755 条（含年 / 月精度）、ISBN 3367 条、系列首卷 ISBN 850 条、日文版发售日 2950 条（任一 ISBN 覆盖 4217 条，87%）
- 文件：`data/light-novels-lite.js`（首屏默认可见，约 458 KB，gzip 约 153 KB）+ `data/light-novels-rest.js`（子卷 / 一般小说 / 重复版本，约 667 KB，gzip 约 170 KB，后台加载）+ `data/light-novels-ch.js`（系列子卷索引，约 94 KB，gzip 约 34 KB，打开系列详情时按需加载）+ `data/light-novels.js`（完整核心，供构建脚本使用）+ `data/light-novels-extra.js`（详情字段，约 596 KB）+ `data/light-novels-volumes.js`（卷包，约 1.35 MB）+ `data/light-novels-rn.js`（扩展书目，约 2.9 MB，gzip 约 721 KB，按需加载）
- 封面在数据里只存相对路径，运行时补全图片域名；图片本身按 100w / 200w / 400w 自适应，列表与看板优先取 100w
- 清洗：优先用 Bangumi 关联接口的「单行本」关系标记子卷，关系缺失时退回标题规则
- 增强：子卷缺失的书系/插图/作者/出版社/题材从父系列继承；漫画、画集、指南写入 `kind`
- 补全：系列条目缺失的书系/插图/作者/出版社从子卷共识继承，首卷日取最早子卷；Bangumi 详情补回 125 条缺失发售日，按年 / 月精度显示（`YYYY` / `YYYY-MM`），不臆造具体日
- 抓取：搜索接口单次最多 1000 条，按评分人数分区抓取后合并去重

## 开发

```bash
npm install
npm run fetch-data    # 抓取全量分页与系列关系，可中断续跑
npm run clean-series  # 用本地缓存离线重算子卷
npm run enrich-openbd # 用 openBD 补日文书系、发售日、ISBN
npm run enrich-detail # 用 Bangumi 详情补缺失日期（可中断续跑）
npm run find-isbn     # 用 RanobeDB 补单册 / 系列首卷 ISBN（每 20 条写回，可中断续跑）
npm run fill-volumes  # 用 RanobeDB 补现有系列缺失卷（可重复运行，增量生成）
npm run build-rn      # 生成 RanobeDB 扩展书目（≥2 卷，默认隐藏）
npm run validate-ranobedb # 生成 RanobeDB 卷目对照报告
npm run check-data    # 数据校验
npm run check-deploy  # 部署边界校验（完整核心不得进入 Pages）
npm run build-pinyin  # 离线重算拼音首字母
npm run test-merge    # 同步合并逻辑单元测试
npm run verify        # 无头浏览器自动化验收（209 项）
```

`npm run verify` 会在 `screenshots/` 输出桌面与移动端截图。push `main` 或 PR 时 GitHub Actions 自动运行 `check-data`、`test-merge` 与 `verify`（Ubuntu 自带 Chrome，失败时上传截图）。

## 部署

GitHub Pages：<https://xyykmkefke.github.io/light-novel-library/>

仓库根目录即站点根目录，无需构建步骤。推送后开启 `main` 分支根目录 Pages 即可。

`_config.yml` 负责部署边界：只发布运行时文件（`index.html`、`manifest.webmanifest`、`sw.js`、`icon.svg`、`icons/` 与 6 个运行时数据包），脚本、报告、截图、文档、`package*.json` 与构建输入（完整核心、`data/*.json`）全部排除出 Jekyll 站点产物。构建输入仍保留在仓库中供 `check-data`、`find-isbn` 与各构建脚本使用；`npm run check-deploy` 会在 CI 中校验排除清单、运行时文件是否被误排除，以及页面/SW 引用是否齐全。

细节见 [HANDOVER.md](./HANDOVER.md)。
