# 轻小说库 · 阅读记录

本地优先的轻小说浏览与阅读记录 PWA。内置 Bangumi「轻小说」标签条目 4007 条，无账号、无后端。

状态：**v1.1.0 已完成**（数据、页面、书评、统计、云同步、PWA、自动化验收 115 项）

v1.1.0：新增我的评分 / 短评 / 笔记与阅读统计页；高级搜索支持作者、年份、评分、题材字段；新增卷数排序、我的评分排序、J/K 键盘导航、安装引导与封面缓存上限清理。

v1.0.1：清理残留代码；纯日文标题补罗马字首字母；评分排序改贝叶斯加权；合并逻辑抽出并新增单元测试；年份条滚动提示；Service Worker 新版本提示。

## 功能

- **全库浏览**：按年份、题材、类型（轻小说 / 漫画 / 画集 / 指南）筛选；评分 / 热度 / 发售日 / 名称排序
- **系列视图**：默认隐藏系列子卷，只显示系列与独立作品；可一键显示全部 4007 条
- **搜索**：中文名、原名、拼音首字母、作者；多关键词交集、`-词` 排除、标题高亮、搜索历史；支持 `作者:` `年:` `分:` `题材:` 字段语法
- **我的阅读**：想读 / 在读 / 读完 / 弃读；系列记录读到第几卷；读满自动标记读完并记录日期
- **我的书评**：1–10 分个人评分、140 字短评、1000 字笔记；随记录一起导出、导入与云同步
- **阅读统计**：收藏与状态总览、年度目标进度、历年与月度读完分布、题材偏好、常读作者
- **视图**：网格 / 列表 / 看板；按年份、题材、阅读状态分组
- **排序**：贝叶斯加权评分、热度、发售日、名称、卷数、我的评分
- **详情**：作者、插图、出版社、书系、册数、发售日、题材、评分、相似推荐、Bangumi 链接；作者与题材标签可一键筛选
- **数据**：JSON / CSV / Markdown 导出，JSON 导入合并，清空可撤销
- **云同步**：GitHub Gist 双向合并，删除墓碑，失败退避重试（Token 仅存本机）
- **PWA**：iOS 添加到主屏幕、安装引导、离线缓存、封面缓存上限、明暗主题
- **无障碍**：跳过头部、焦点陷阱、Esc 归焦、状态播报、J/K 键盘导航、44px 触控目标

## 数据

- 来源：Bangumi（bgm.tv），`type=1` 书籍，`tag=轻小说`，通过镜像 `bgmapi.anibt.net` 抓取
- 规模：4007 条；系列 1123 / 单册 2884 / 系列子卷 2028；默认可见 1979 条
- 文件：`data/light-novels.js`（已生成并随仓库提交）
- 清洗：优先用 Bangumi 关联接口的「单行本」关系标记子卷，关系缺失时退回标题规则
- 增强：子卷缺失的书系/插图/作者/出版社/题材从父系列继承；漫画、画集、指南写入 `kind`
- 抓取：搜索接口单次最多 1000 条，按评分人数分区抓取后合并去重

## 开发

```bash
npm install
npm run fetch-data    # 抓取全量分页与系列关系，可中断续跑
npm run clean-series  # 用本地缓存离线重算子卷
npm run check-data    # 数据校验
npm run build-pinyin  # 离线重算拼音首字母
npm run test-merge    # 同步合并逻辑单元测试
npm run verify        # 无头浏览器自动化验收（115 项）
```

`npm run verify` 会在 `screenshots/` 输出桌面与移动端截图。
