# 轻小说库 · 阅读记录

本地优先的轻小说浏览与阅读记录 PWA。内置 Bangumi「轻小说」标签条目，无账号、无后端。

状态：**初始骨架 v0.1.0**（目录、数据规范、落实与交接文档已就绪，业务功能待实现）

## 规划功能

- **全库浏览**：按年份、题材、系列 / 单册筛选，评分 / 热度 / 发售日 / 名称排序
- **搜索**：多关键词交集、`-词` 排除、拼音首字母、标题高亮、搜索历史
- **我的阅读**：想读 / 在读 / 读完 / 弃读；系列条目记录读到第几卷；读完自动记录日期
- **视图**：网格 / 列表 / 看板；按年份、题材、状态分组
- **详情**：作者、插图、出版社、书系、册数、发售日、题材、评分、相似推荐
- **数据**：JSON / CSV / Markdown 导出，JSON 导入合并
- **云同步**：GitHub Gist 双向合并（可选，Token 仅存本机）
- **PWA**：iOS 添加到主屏幕、离线缓存
- **无障碍**：键盘导航、焦点陷阱、状态播报、44px 触控目标

## 数据

- 来源：Bangumi（bgm.tv），`type=1` 书籍，`tag=轻小说`
- 规模：约 4000 条，其中系列条目约七成
- 文件：`data/light-novels.js`（待生成）
