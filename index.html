键盘快捷键

  • /聚焦搜索框
  • ←→上一本 / 下一本（详情内）
  • ↑↓在卡片间移动焦点（也可用 K / J）
  • Enter打开当前聚焦的书目
  • T切换明暗主题
  • Esc关闭详情或本帮助
  • ?打开 / 关闭本帮助
  • 长按快捷菜单；Ctrl K 打开命令面板

云同步（GitHub Gist）

用一个只包含 gist 权限的 Token，把阅读记录存进你的私有 Gist，多台设备打开时自动合并。

Token 只保存在本机浏览器，同步时数据直连 api.github.com，不经过其他服务器。换设备时用同一个 Token 和 Gist ID 即可接上。
